# Klávesové skratky

⌘ = Command · ⇧ = Shift · ⌥ = Option · ⌃ = Control

## Karty

| Skratka | Akcia |
|---|---|
| ⌘T | Nová karta |
| ⌘W | Zavrieť kartu |
| ⌘⇧T | Znova otvoriť zatvorenú kartu |
| ⌘⇧] | Ďalšia karta |
| ⌘⇧[ | Predchádzajúca karta |
| ⌘1 … ⌘8 | Prepnúť na kartu 1–8 |
| ⌘9 | Posledná karta |
| Stredné tlačidlo myši na karte | Zavrieť kartu |
| Dvojklik na prázdny riadok kariet | Nová karta |

## Navigácia

| Skratka | Akcia |
|---|---|
| ⌘L | Adresný riadok |
| ⌘R | Obnoviť stránku |
| ⌘[ | Späť |
| ⌘] | Vpred |
| ⌘⇧H | Domovská stránka |
| Enter (v adresnom riadku) | Otvoriť / vyhľadať |
| Esc (v adresnom riadku) | Zrušiť úpravu |

## Hľadanie na stránke

| Skratka | Akcia |
|---|---|
| ⌘F | Otvoriť hľadanie |
| ⌘G / Enter | Ďalší výsledok |
| ⌘⇧G / ⇧Enter | Predchádzajúci výsledok |
| Esc | Zavrieť hľadanie |

## Zobrazenie

| Skratka | Akcia |
|---|---|
| ⌘+ (⌘=) | Priblížiť |
| ⌘− | Oddialiť |
| ⌘0 | Predvolené priblíženie |
| ⌃⌘F | Celá obrazovka |

## Panely

| Skratka | Akcia |
|---|---|
| ⌘, | Nastavenia |
| ⌘Y | História |
| ⌘⌥B | Obľúbené |
| ⌘⌥L | Stiahnuté |
| ⌘D | Pridať / odobrať stránku z obľúbených |
| Esc | Zavrieť panel |
| ⌘+klik na položku | Otvoriť v novej karte |

## Úpravy textu

| Skratka | Akcia |
|---|---|
| ⌘Z / ⌘⇧Z | Späť / Znova |
| ⌘X / ⌘C / ⌘V | Vystrihnúť / Kopírovať / Vložiť |
| ⌘A | Označiť všetko |

## Aplikácia

| Skratka | Akcia |
|---|---|
| ⌃⌘L | Zamknúť Crow (uloží a zašifruje všetko) |
| ⌘H | Skryť |
| ⌘⌥H | Skryť ostatné |
| ⌘M | Minimalizovať |
| ⌘Q | Ukončiť (uloží a zašifruje všetko) |

## Linux

Rovnaké akcie, ⌘ sa mení na Ctrl. Navyše platia bežné linuxové aliasy. Číslice a interpunkcia sa rozpoznávajú podľa fyzickej klávesy, takže fungujú aj na slovenskej klávesnici.

| macOS | Linux |
|---|---|
| ⌘T / ⌘W / ⌘⇧T | Ctrl+T / Ctrl+W (Ctrl+F4) / Ctrl+Shift+T |
| ⌘⇧] / ⌘⇧[ | Ctrl+Tab, Ctrl+PgDn, Ctrl+Shift+] / Ctrl+Shift+Tab, Ctrl+PgUp, Ctrl+Shift+[ |
| ⌘1 … ⌘9 | Ctrl+1 … Ctrl+9 |
| ⌘L | Ctrl+L, Alt+D, F6 |
| ⌘R | Ctrl+R, F5 |
| ⌘[ / ⌘] | Alt+← / Alt+→ (aj Ctrl+[ / Ctrl+]) |
| ⌘⇧H | Alt+Home, Ctrl+Shift+H |
| ⌘F / ⌘G / ⌘⇧G | Ctrl+F / Ctrl+G, F3 / Ctrl+Shift+G, Shift+F3 |
| ⌘+ / ⌘− / ⌘0 | Ctrl++ / Ctrl+− / Ctrl+0 |
| ⌃⌘F | F11 |
| ⌘, / ⌘Y | Ctrl+, / Ctrl+H, Ctrl+Y |
| ⌘⌥B / ⌘⌥L | Ctrl+Shift+B / Ctrl+Shift+Y |
| ⌘D | Ctrl+D |
| ⌃⌘L | Ctrl+Shift+L |
| ⌘Q | Ctrl+Q |
| ⌘+klik | Ctrl+klik |
